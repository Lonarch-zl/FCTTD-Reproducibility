# Model Checkpoints

Model checkpoints (`.pt` files) for the FCTTD experiments are hosted separately on OSF because of their file sizes.

**OSF view-only link (for peer review):** [Access model checkpoints](https://osf.io/nrwdk/overview?view_only=2460b33a2ef6453e98e30ea4773941b1)

Download the required checkpoint files from OSF and place them in this `checkpoints/` directory. Refer to the repository's main `README.md` and evaluation scripts for reproduction instructions.
